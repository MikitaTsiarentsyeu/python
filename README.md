This simplified Python course is part of "Algorithms and Data Structures" taught at the School of Digital Competencies in Vilnius (https://en.ehu.lt/studies/computer-science/). I compiled it based on my experience teaching students of various levels and backgrounds, aiming to provide a coherent and accessible way to learn Python at their own pace. While it's possible to learn Python using these materials without a teacher, they were designed with direct student communication in mind, which is the preferred approach. Each lesson includes practical tasks and homework, and there are final projects that introduce basic data structure creation in Python.

Most materials are in Jupyter notebook format, so install it before starting (https://jupyter.org/).
